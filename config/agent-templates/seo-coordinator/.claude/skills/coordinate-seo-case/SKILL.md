# Coordinate SEO Case

1. Validate the operator brief and create a case identifier.
2. Send only the required control message to the next Team member.
3. Record every handoff and review attempt in the case state.
4. Preserve evidence and never bypass `seo-reviewer`.
5. Escalate after three Reviewer FAIL results.
